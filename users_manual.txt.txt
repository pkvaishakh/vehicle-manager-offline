========================================
  Vehicle Management System v1.0
========================================

HOW TO RUN:
  Double-click VehicleManager.exe

DATA LOCATION:
  All data is saved in the same folder
  as VehicleManager.exe

  vehicles.db = Your vehicle database
  (DO NOT delete this file!)

BACKUP:
  Copy vehicles.db to a safe location

IMPORT DATA:
  Prepare CSV with columns:
  vehicle_number, phone, expiry_date

  Click: Vehicles → Import CSV

REQUIREMENTS:
  - Windows 10/11
  - WhatsApp Desktop (for auto-send)
  - No Python installation needed!

Backup & Move Data

To BACKUP your data:
   Copy: vehicles.db → somewhere safe

To MOVE to another PC:
   Copy these files:
   ├── VehicleManager.exe
   └── vehicles.db          ← Your data!

To RESET (fresh start):
   Delete: vehicles.db
   (App creates new empty database on next run)
