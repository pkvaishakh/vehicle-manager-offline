========================================
  Vehicle Management System v1.0
========================================

HOW TO RUN:
  Double-click VehicleManager.exe

DATA LOCATION:
  All data is saved in the same folder
  as VehicleManager.exe

  vehicles.db = Your vehicle database
  (DO NOT delete this file!)

BACKUP:
  Copy vehicles.db to a safe location

IMPORT DATA:
  Prepare CSV with columns:
  vehicle_number, phone, expiry_date

  Click: Vehicles → Import CSV

REQUIREMENTS:
  - Windows 10/11
  - WhatsApp Desktop (for auto-send)
  - No Python installation needed!

SMS REMINDER:
  1. Click: SMS
  2. Enter the local SMS gateway URL from the SMSGate app
  3. Optionally enter username and password
  4. Use the message template or leave blank for defaults
  5. Set the expiry date range using the From/To fields
  6. Use the quick filter buttons on the new row below the dates
  7. Preview the message, then click Start Bulk SMS

WHATSAPP BULK SEND:
  1. Click: WhatsApp
  2. Make sure WhatsApp Desktop is installed for auto-send
  3. Set the expiry date range using the From/To fields
  4. Use the quick filter buttons on the new row below the dates
  5. Set delay between messages before starting
  6. Click Start Bulk Send to send reminders

Backup & Move Data

To BACKUP your data:
   Copy: vehicles.db → somewhere safe

To MOVE to another PC:
   Copy these files:
   ├── VehicleManager.exe
   └── vehicles.db          ← Your data!

To RESET (fresh start):
   Delete: vehicles.db
   (App creates new empty database on next run)
